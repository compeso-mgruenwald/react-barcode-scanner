# Example

Vite+ app for trying `@thewirv/react-barcode-scanner` in a browser. It is a workspace package; install once from the repo root.

```bash
bun install
bun run dev
```

`bun run check` from the repo root also builds this app. App-specific Vite settings are in `apps/example/vite.config.ts`. Shared fmt and lint live in the root `vite.config.ts`.
